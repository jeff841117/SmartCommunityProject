# 資料庫腳本說明

這個資料夾用來放「真的要執行」的資料庫腳本，不只是規格筆記。

目前規則：
- 每一批資料庫變更都盡量獨立成單一腳本
- 檔名用日期開頭，方便之後追蹤執行順序
- 腳本內優先使用可重複執行的寫法，避免測試資料庫重跑時直接失敗
- 先新增欄位 / 新增資料表，不急著刪舊欄位

## 目前腳本

### `Phase2/20260428_Phase2SchemaPrepare.sql`

用途：
- 幫第二階段預約規則與忘記密碼流程先把資料表落點建好
- 把第一階段已經收斂出的欄位需求，整理成可執行 SQL
- 讓後續的 `未來時段預約`、`預約轉排隊`、`密碼找回`、`管理者操作紀錄` 有正式 schema 可以接

建議執行順序：
1. 先在 `sql_db_test` 備份或確認資料
2. 再執行 `20260428_Phase2SchemaPrepare.sql`
3. 執行後用查詢確認欄位與資料表都有建立成功
4. 確認成功後，再開始做第二階段程式碼實作
