# 智能社區收費系統 (SmartCommunity)

ASP.NET Core MVC（Visual Studio）+ SQL Server 收費系統，用於展示以下功能：

* 使用者註冊與管理者帳單資料管理
* 帳單查詢與繳費（現金 / ATM / LINE Pay）
* 顯示 QR Code（模擬 LINE Pay）
* ASP.NET Core MVC 8（Razor Views）
* Identity（登入 / 角色 / Cookie 身分驗證）
* Entity Framework Core + SQL Server
* Bootstrap（前端樣式）

## 📁 專案結構

SmartCommunity/

├─ Controllers/

│  ├─ BillsController.cs         ← 住戶未繳帳單 / 管理者清單

│  ├─ PaymentsController.cs      ← 繳費紀錄 / 住戶付款

│  └─ AdminUsersController.cs    ← 管理者維護住戶資料

├─ Data/

│  └─ SmartCommunityContext.cs   ← EF Core DbContext（含 Identity）

├─ Models/

│  ├─ User.cs                    ← 住戶資料（房號、姓名、Email、AspNetUserId）

│  ├─ Bill.cs                    ← 帳單

│  ├─ FeeItem.cs                 ← 收費項目（管理費、水、電…）

│  └─ Payment.cs                 ← 繳費紀錄（PayDate/PayAmount/PayMethod 對應）

├─ Views/

│  ├─ Shared/\_Layout.cshtml

│  ├─ Bills/MyUnpaid.cshtml      ← 住戶自己的未繳帳單（含付款彈窗）

│  ├─ Payments/MyHistory.cshtml  ← 住戶繳費紀錄

│  └─ AdminUsers/{Index,Edit}.cshtml

├─ appsettings.json               ← 連線字串與種子管理者設定

└─ Program.cs                     ← 服務註冊與管理者/角色初始化

## 🚀 執行方式

1. 啟動伺服器：智能社區.sln

## 💳 測試流程

1. 登入帳號 → 進入功能選單
   管理者帳號:admin@gmail.com 密碼:123456
2. 查詢帳單 → 選擇付款方式 → 確認
3. 查看繳費紀錄（可看到最近繳費方式與時間）
4. 管理者帳號(可新增用戶帳單或修改用戶資料)

## 🧾 注意

* 管理費固定 3000 元
* 使用SQL可調整收費倍率，使用者可以直接調整用戶資料
* LINE Pay 僅為測試 QR Code，不具實際付款功能
