智能社區收費系統 (SmartCommunity)

ASP.NET Core MVC（Visual Studio）+ SQL Server 收費系統，用於展示以下功能：

使用者註冊與管理者帳單資料管理

帳單查詢與繳費（現金 / ATM / LINE Pay）

顯示 QR Code（模擬 LINE Pay）

ASP.NET Core MVC 8（Razor Views）

Identity（登入 / 角色 / Cookie 身分驗證）

Entity Framework Core + SQL Server

Bootstrap（前端樣式）

📁 專案結構

SmartCommunity/

├─ Controllers/

│  ├─ BillsController.cs          ← 使用者：未繳帳單列表（僅顯示/跳轉付款）

│  ├─ PaymentsController.cs       ← 使用者：付款邏輯、繳費紀錄

│  ├─ AdminBillsController.cs     ← 管理者：帳單管理（列表、新增、刪除）

│  ├─ AdminUsersController.cs     ← 管理者：住戶管理（列表、編輯、刪除）

│

├─ Views/

│  ├─ Bills/

│  │  └─ MyUnpaid.cshtml          ← 使用者：未繳帳單（付款彈窗）

│  │

│  ├─ Payments/

│  │  └─ MyHistory.cshtml         ← 使用者：繳費紀錄列表（只顯示）

│  │

│  ├─ AdminBills/

│  │  ├─ Index.cshtml             ← 管理者：帳單列表（查看所有住戶）

│  │  └─ Create.cshtml            ← 管理者：新增帳單

│  │

│  ├─ AdminUsers/

│  │  ├─ Index.cshtml             ← 管理者：所有住戶資料清單

│  │  └─ Edit.cshtml              ← 管理者：編輯住戶資料

│

├─ Models/ (資料表綁定的實體)

│  ├─ User.cs                     ← 住戶資料（含對應 AspNetUserId）

│  ├─ Bill.cs                     ← 帳單主資料（住戶、費用、金額、狀態）

│  ├─ FeeItem.cs                  ← 費用項目設定（管理費/水費/電費 單價等）

│  ├─ Payment.cs                  ← 付款紀錄（帳單ID、方式、付款日等）

│

├─ Data/

│  └─ SmartCommunityContext.cs    ← EF Core DbContext（資料表註冊 + Fluent 設定）

│

├─ Views/Shared/

│  ├─ \_Layout.cshtml              ← 共用版面（包含 Admin 之導覽判斷）

│  └─ \_ValidationScriptsPartial.cshtml

│

├─ wwwroot/                       ← 前端靜態檔案（如自訂 CSS/圖片/QR Code）

│

├─ appsettings.json               ← 資料庫連線字串、設定

└─ Program.cs / Startup.cs        ← MVC、身份驗證、角色設定
