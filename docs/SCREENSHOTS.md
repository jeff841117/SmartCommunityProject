# 畫面清單與檔名規範

本文件整理作品集 README 建議使用的畫面清單，以及建議的檔名。

---

## 建議畫面

1. 登入頁
2. 設備預約頁
3. 我的預約頁
4. 設備管理頁
5. 預約與排隊總覽頁
6. 管理者操作紀錄頁
7. Swagger 頁面

---

## 建議檔名

請將截圖放在：

```text
docs/screenshots/
```

建議檔名：
- `login.png`
- `reservation.png`
- `my-reservations.png`
- `equipment-admin.png`
- `dashboard.png`
- `action-logs.png`
- `swagger.png`

---

## 每張圖建議呈現的內容

### 1. 登入頁
- 專案標題
- 帳號 / 密碼欄位
- 作品集版視覺風格

### 2. 設備預約頁
- 設備卡片
- 立即使用按鈕
- 預約時間查詢
- 篩選區塊

### 3. 我的預約頁
- 使用中
- 排隊中
- 未來預約
- 歷史記錄摺疊區

### 4. 設備管理頁
- 設備表格
- 編輯 / 刪除
- 設備種類欄位

### 5. 預約與排隊總覽頁
- 設備摘要
- 未來預約
- 使用中
- 排隊中
- 高風險設備篩選

### 6. 管理者操作紀錄頁
- 篩選表單
- 分頁
- 匯出功能

### 7. Swagger
- Swagger 首頁
- 至少展開 1~2 個代表性 endpoint

---

## 補充說明

目前如果還沒有實際截圖，可以先保留這份檔名規劃。
之後只要把實際 PNG 放進 `docs/screenshots/`，README 就能直接引用。
